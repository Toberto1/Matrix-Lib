# Matrix-Manipulator
A small C library for basic matrix operations. 
Built this as a calculator for my linear algebra class, for easily handling computations like solving systems of equations and manipulating matrices without doing anything by hand.

What it does:
Addition: Add two matrices
Subtraction: Sub two matrices
Multiplication: Multiply two matrices
Transpose: Flip a matrix over its diagonal
Solve Ax = b: Solve linear systems using Gaussian elimination
